# Village experience

Warm late-afternoon Bengal: leafy green, rice fields, cream plaster, terracotta, teal shutters and yellow station trim. Actual interactive 3D world is the first viewport. UI is legible cream/forest-green with restrained ochre accents, clear touch targets and no marketing layout. Bengali text uses Noto Sans Bengali when available. Compact time and money HUD; contextual actions; one task at a time. World art is illustrative until verified against current local references.

Tokens reflect the current stylesheet: forest #163e32, deep forest #102e25, cream #faf5e9, gold #e5bc65, ink #213e32, muted green #617265. Fonts: DM Sans and Noto Sans Bengali, with sans-serif fallbacks. Panel radius 16px; compact surfaces use 12px. Controls target a minimum of 44px. Shadows use soft offset blur. Full-screen landscape game supports portrait through compact controls and a rotate suggestion, without blocking play.

The surface is an experience: the playable 3D village leads, and the interface supplies time, money, current task and nearby actions. Cream action panels and forest-green HUD surfaces belong to the same village palette. Gold identifies the primary start action and emphasis. Bengali landmark text and the village view carry the local identity.

Keep the same world, activities and progression across Android and PC. Adapt input and rendering detail to each device. Current facade artwork is illustrative until checked against local references. The current evidence supports a bounded desktop interaction check; mobile QA and a full visual review remain outstanding. Detailed verification status is recorded in docs/BUILD_STATUS.md.
