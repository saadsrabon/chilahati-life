# Chilahati Life

A browser-first 3D village simulation for Android and PC, based on Chilahati, Domar, Nilphamari, Bangladesh.

## Run

Requires Node.js 22.12+ (Node 24 recommended).

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Status

First playable prototype in active development. Geographic source coverage and current landmark appearance are under verification. Procedural facades and fictional NPCs are illustrative. This is not a claim that every building or named market has been surveyed or recreated.

## Controls

PC: WASD movement, mouse drag camera, Shift sprint, E interact, V transport, M map, Esc menu.
Android: on-screen movement, camera drag, contextual interactions and vehicle controls.

## Data

Road/rail snapshots, when available, are credited to OpenStreetMap contributors under ODbL. See docs/MAP_SOURCES.md. Shops, ownership, prices, disputes and progression are fictional game systems.

## Roadmap

- Playable station area and village routines
- Real road and railway foundation across the agreed area
- Van, bicycle and motorcycle rental/ownership
- Jobs, trade, homes, schooling, debt and police simulation
- Locally verified facades and Bengali signs
- Verified mosque timetable and approved azan recordings

No real azan audio is bundled until a suitable recording is approved and sourced.
