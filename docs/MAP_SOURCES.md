# Geographic data status

The released station-area scene is an illustrative gameplay layout. It is not the surveyed road network of Chilahati. Botolganj, Kazirhat, Boaed Bazar and Bouer Bazar remain required coverage areas in the full plan.

scripts/fetch-map.mjs is prepared to collect and normalize a public OpenStreetMap snapshot around the station. This development session could not complete the download because the execution environment could not resolve the Overpass/API hosts. No invented map snapshot has been substituted.

Source intended: OpenStreetMap contributors, https://www.openstreetmap.org/copyright, ODbL-1.0. The script preserves origin coordinates, roads, railway lines and mapped points where returned. The requested bbox is only a development data request; it is not a confirmed boundary of the user's full intended Chilahati area.

Exact roads, entrances, place names, current facades and the outer perimeter need a successful source import and local verification. Boaed Bazar's Bengali name/pin remains unresolved. Station architectural reference work is documented in VISUAL_REFERENCES.md.
